Про мене

Швидко навчаюся новому та відкритa до роботи в сферах, пов’язаних із технологіями, програмуванням і веб-розробкою.Маю досвід у створенні адаптивних, сучасних і функціональних веб-сайтів, добре орієнтуюсь у принципах frontend і backend. Постійно вдосконалюю свої навички та готова до освоєння нових технологій.

    Front-End:
  • HTML5, CSS3 – впевнене володіння, створення адаптивної верстки (flexbox, grid).
  • JavaScript – розробка інтерактивного функціоналу, робота з DOM, обробка подій.
  • React – базовий рівень: створення компонентів, хуки (useState, useEffect).
  • Bootstrap, SASS – використання для швидкої розробки та стилізації.
  • jQuery – робота з DOM.
    Back-End:
  • PHP – базові знання: створення серверної логіки для простих застосунків.
  • WordPress – розробка та кастомізація тем, налаштування плагінів.
  • MySQL – створення структур баз даних, написання SQL-запитів.
    API та інтеграції:
  • REST API – досвід взаємодії з API: отримання та передача даних за допомогою fetch/axios.
    Додатково:
  • Git, GitHub. Gulp. Python, C# – базовий рівень для вирішення навчальних і прикладних задач.

Навчаюся заочно, що дозволяє поєднувати освіту з практичною діяльністю. Шукаю можливості для професійного розвитку, готова до нових викликів і поглиблення знань у програмуванні та веб-розробці.
